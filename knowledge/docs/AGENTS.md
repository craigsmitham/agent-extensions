# Maintaining the docs bundle

- For every cataloged document form, maintain three standalone pages. The
  explainer shows how the form works and why. The guide helps a writer produce
  and check one. The pattern helps a reader judge when the design fits.
- Draft explainers and guides from reader questions, primary sources, and worked
  examples. Use Diátaxis for the forms it covers. Follow the bundle’s guides
  to writing explainers and how-to guides.
- Give each substantive explanation or procedure one maintained home. Keep
  enough context for direct lookup. Link from the pattern to a companion where
  the reader’s next question calls for it.
- Keep indexes and docs skill routes aligned with reader intent. When an
  authoring route changes, try it on a fresh brief and assess the resulting
  document against its reader’s goal.
