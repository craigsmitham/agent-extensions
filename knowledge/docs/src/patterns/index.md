# Documentation pattern collection

Choose by the reader's problem. Each description connects a reusable document design to its applicability, tradeoffs, evidence, relationships, and authoring guidance. For selection and combination examples, see [Documentation craft](../explainers/documentation-craft.md#select-and-combine-patterns).

## Patterns

* [Explanation](explanation.md) - When readers need to reason about a subject, connect concepts, consequential distinctions, and examples into a bounded account that develops understanding.
* [How-to guide](how-to.md) - When competent readers need to achieve a bounded real-world goal, organize adaptable directions around the task, its conditions, and a verifiable result.
* [Pattern collection](pattern-collection.md) - When readers need to choose among related patterns, offer routes from their situations to useful choices, explain complementary or opposing responses, and maintain shared knowledge through feedback from use.
* [Pattern description](pattern-description.md) - When recurring design experience needs to be shared, name its essential property or strategy and explain context, variation, consequences, and evidence so practitioners can recognize and adapt it.
* [Playbook](playbook.md) - For a recurring class of situations requiring assessment and judgment, guide practitioners in choosing, combining, and adapting responses with explicit coordination and escalation.
* [Principle document](principle.md) - When recurring decisions need durable direction, document the good sought, its warrant, scope, and practical implications so readers can exercise situated judgment.
* [Reference](reference.md) - When readers need authoritative facts during work, organize accurate, consistently structured entries around the system so they can locate and compare details quickly.
* [Runbook](runbook.md) - For a bounded operational task with an established procedure, specify repeatable execution with explicit conditions, verification, recovery, and escalation.
* [Tutorial](tutorial.md) - When readers need to acquire a skill, lead them through a safe, bounded lesson with meaningful actions and visible results that build confidence for further practice.
