# Testing pattern collection

Patterns for expressing executable specifications, selecting faithful test worlds, and sustaining owned test evidence. Coverage is partial; draft formulations identify their evidence limits.

## Concepts

- [Evidence-matched test world](evidence-matched-test-world.md) — Chooses the smallest test world that preserves material failure distinctions, with explicit boundaries, substitutions, and evidence limits.
- [Executable specifications](executable-specifications.md) — When intended behavior must be shared with its owners and checked continuously, express accepted rules in readable specifications bound to executable checks while keeping authority separate from verification.
- [Owned test worlds](owned-test-world.md) — Makes spanning tests accountable and repeatable through owned state, observable readiness, interruption-safe cleanup, and attributable evidence.
