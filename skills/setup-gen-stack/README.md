# Set up Gen Stack

Plans or establishes the smallest discoverable OKF v0.2 corpus adopting the
`gen-stack` profile. It creates the cross-cutting System governance kernel from
accepted authority, connects admitted Intent and Architecture concepts, and
adds the governed System Evaluation Approach and one persistent discovery
route.

It does not invent system meaning or move repository-native Implementation,
concrete Evaluation artifacts, Signals, or Observations into the corpus.
