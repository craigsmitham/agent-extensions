# Implement

Executes an authorized implementation-ready plan and produces one identifiable
candidate revision with attributable verification and visible deviations. It
preserves unrelated work, delegates planned focused reviews of stable
increments, dispositions every review action, and returns newly exposed meaning
or design decisions to their owners without activating another stage.

Implement is a deliberate Gen Stack stage. Select `$implement` explicitly;
ordinary requests to build or fix software do not activate this workflow.

Checkpoint review feedback is not final assurance. Implementation hands the
exact candidate to a fresh integrated review and never ships its own result.
Install this non-standalone skill through `@craigsmitham/packs/gen-stack`.
