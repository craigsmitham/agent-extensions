# Reconcile Gen Stack

Assesses or reconciles an established OKF v0.2 corpus against `gen-stack`
profile `0.1.0`. It covers cross-cutting governance, Intent, Architecture,
subject-colocated Requirements, the System Evaluation Approach, navigation,
authority, and lifecycle while reporting OKF, profile, and coverage or fitness
claims separately.

Repository-native Implementation, concrete Evaluations, Signals, and
Observations are checked as related authorities, not migrated into corpus
concept collections.
