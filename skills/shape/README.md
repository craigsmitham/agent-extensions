# Shape

Shapes a raw request, issue, opportunity, proposal, or mixed body of context
into a rough, bounded, repository-grounded Pitch suitable for discussion and a
formal response from specification or design.

Shape is a deliberate Gen Stack stage. Select `$shape` explicitly; ordinary
requests to frame or clarify work do not activate this workflow.

The Pitch includes the problem or opportunity, intended outcome, appetite,
boundaries, anticipated Gen Stack impact, an inline filesystem breadboard,
rough response contours, risks, authority, and an exact requested response.
Depending on uncertainty and consequence, `$shape` can draft immediately,
draft provisionally and elicit, discover first, or recommend `$research`,
`$investigate`, a human decision, or no change without activating another
stage.

It may anticipate which Requirement-satisfaction or Architecture-realization
Evaluation Protocol meaning is affected, but remains agnostic about
implementation-level Evaluations and tests. Existing test artifacts are
evidence, not projected Pitch changes.

Shape does not accept desired state, select the technical response, create an
implementation plan, set priority, or authorize change. Install it through
`@craigsmitham/packs/gen-stack`; it depends on the pack's canonical shaping and
change-realization guidance and is not standalone.
