# Behavioral evaluation cases

The machine-readable authority is `evals.json`. Run each case in a fresh,
disposable context with the Gen Stack knowledge support path. The suite covers
immediate, provisional, elicitation-first, solution-biased, unavailable-
filesystem, no-change, and implementation-level Evaluation/test-agnosticism
execution, plus explicit selection and implicit abstention across adjacent
specification, design, research, and investigation requests. Missing
filesystem or side-effect evidence is `unknown`, never an inferred pass.
