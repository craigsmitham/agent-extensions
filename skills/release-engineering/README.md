# Release engineering

Design a repository’s delivery workflow or assess a specific change when deciding whether to integrate, deploy, expand exposure, or close the work.

Install the [software-engineering pack](https://github.com/craigsmitham/agent-extensions/tree/main/packs/software-engineering) for the skill and the companion knowledge it uses.

```sh
axm install @craigsmitham/packs/software-engineering
```

Ask “My change passed locally, then another agent updated the producer on main. Is my consumer ready?” Expect a decision grounded in what changed, which results remain valid, and what check would settle any remaining doubt.
