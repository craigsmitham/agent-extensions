# Git Tidy

Review Git housekeeping by batch across repositories on a machine.

```sh
axm install @craigsmitham/skills/git-tidy
```

Try “Scan the repos under my projects directory with git-tidy.” The first
report groups merged branches, linked checkouts, stashes and uncertain
findings by the decision they need. Reply “show A” to inspect a group or
“remove finished checkouts in api and keep the branches” to narrow an action.
