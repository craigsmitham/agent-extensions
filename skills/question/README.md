# Question — deprecated

Question is no longer a separately maintained Gen Stack workflow. Its
concern-aware, hypothesis-neutral Research Brief framing contract moved into
Research `3.0.0` at `references/framing-research.md`.

Install `@craigsmitham/packs/gen-stack` and use Research with framing-only
intent:

```text
/research Frame the five questions most likely to change this decision. Return
the Research Brief without conducting the research.
```

The compatibility skill only forwards an explicit legacy invocation. It is not
included as a separate entry point in the Gen Stack pack.
