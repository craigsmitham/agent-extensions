Architecture, subject-colocated Requirement, and System Evaluation Approach
concepts in an established OKF v0.2 corpus adopting `gen-stack` profile
`0.1.0`.

requires human authority for accepted meaning and Requirement subject choice,
and creates only the navigation earned by the requested concept.
