# Software engineering

An optional aggregate of the seven discipline collections. It installs seven
knowledge bundles and seven placeholder skills. Existing knowledge is partial;
the release-engineering knowledge bundle and all seven skills are placeholders.

AXM packs do not nest. This pack lists each discipline’s skill and knowledge
bundle directly.

## Disciplines

| Discipline | Included identities |
| --- | --- |
| business-analysis | `@craigsmitham/skills/business-analysis`, `@craigsmitham/knowledge/business-analysis` |
| requirements-engineering | `@craigsmitham/skills/requirements-engineering`, `@craigsmitham/knowledge/requirements-engineering` |
| architecture-and-design | `@craigsmitham/skills/architecture-and-design`, `@craigsmitham/knowledge/architecture-and-design` |
| software-testing | `@craigsmitham/skills/software-testing`, `@craigsmitham/knowledge/software-testing` |
| release-engineering | `@craigsmitham/skills/release-engineering`, `@craigsmitham/knowledge/release-engineering` |
| software-operations | `@craigsmitham/skills/software-operations`, `@craigsmitham/knowledge/software-operations` |
| project-management | `@craigsmitham/skills/project-management`, `@craigsmitham/knowledge/project-management` |

Discipline packs provide smaller selections containing their skill and knowledge bundle.

## Install

```sh
axm install @craigsmitham/packs/software-engineering
```
