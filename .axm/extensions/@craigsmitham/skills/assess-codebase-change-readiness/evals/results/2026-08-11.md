## Iteration evidence

Three preliminary fixtures claimed readiness without supplying all evidence
their own contracts required. The first diagnostic-field run correctly found no
retry-preservation check. The first accepted-risk run found no key-separation
test and no objective old-key-removal gate. The first flag-retirement run found
that “production equivalence” was named but not defined, so the gap was partly
specification rather than planning. Each fixture was completed and rerun in a
fresh context; the skill was not weakened to force `Ready` or a narrower route.

The first contradictory-contract run passed its assertions but exposed unrelated
missing verification detail in the fixture. That evidence was completed and the
case was rerun so the final result isolates authoritative contradiction rather
than document incompleteness.

One final isolated run per case is reported above. Human grading used the
assertions in `evals/evals.json`. These results establish directional behavioral
coverage, not statistical reliability across models or repeated samples.
