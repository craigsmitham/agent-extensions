# Forward evaluation: 2026-08-10

Evaluated the current `0.0.2` working revision in separate fresh agent contexts.
Each run received only the selected `SKILL.md`, its prompt, and resources the
skill itself instructed the agent to read. Evaluation metadata and expected
assertions were withheld until human grading. All prompts were synthetic.

| Case | Assertions passed | Observation |
| --- | ---: | --- |
| Relevant research-to-design drift | 4/4 | Paused only the stale ownership decision and asked a scoped current-state question. |
| Irrelevant research-to-design drift | 4/4 | Preserved the snapshot distinction without demanding refreshed research merely because the repository advanced. |
| Snapshot changes before acceptance | 4/4 | Reopened the persistence-dependent decision and kept the design unaccepted. |
| Functional ambiguity blocks acceptance | 4/4 | Assigned stable IDs, blocked specification, and required an acceptance evidence identity. |
| Direct evidence without Git or a research report | 4/4 | Used the named export and capture time without inventing Git provenance. |
| One consequential decision at a time | 4/4 | Presented only the first dependency-ordered decision and waited for explicit choice. |
| Design request that also asks for planning | 5/5 | Kept planning in a separate later workflow and requested frame confirmation. |
| No consequential design choice | 3/3 | Declined a disproportionate workshop without manufacturing a record or agenda. |
| **Total** | **32/32** | |

The acceptance and planning-boundary cases each received one earlier diagnostic
run. The first acceptance run omitted an ID for the unresolved behavior and did
not require the design-time evidence identity; the skill was tightened and the
retest passed 4/4. The first planning-boundary run deferred planning output but
promised to produce it later inside the workshop; the skill was tightened to
require a separate workflow and the retest passed 5/5.

One final isolated run per case is reported above. These results establish a
directional behavioral check, not statistical reliability.
