## Iteration evidence

The first structural-only run scored 2/4 because it created a `B<n>` that merely
restated preserved behavior. The skill was revised to require `N/A — no
observable behavior change` and an equivalence-backed structural slice; a fresh
run then scored 4/4.

Preliminary prompts for the non-Git, harmless-drift, and planning-boundary cases
named accepted identifiers without supplying all consequential contract content.
The skill correctly blocked those prompts. The synthetic fixtures were completed
before the graded runs so each case isolated its intended behavior.

One final run per case was graded. The results show conformance for these
scenarios, not statistical reliability across models or repeated samples. Timing
and token counts were not available from the evaluation surface.
