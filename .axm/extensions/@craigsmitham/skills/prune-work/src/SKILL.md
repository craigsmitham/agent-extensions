# Prune work

Reduce claims on attention while preserving useful evidence. An item's presence
does not entitle it to remain open.

## Establish the boundary

- Identify the collection, requested decision, current goals or obligations,
  decision authority, and any protected work. Ask only when a missing answer
  could materially change the safety or meaning of the pruning.
- Treat age and inactivity as review signals, not proof that work is worthless.
  Check whether inactivity instead reflects an unanswered request or another
  party's delay.
- Use supplied workflow and retention rules. Do not invent meanings for
  statuses or assume that closing and deleting are equivalent.

## Test continued inclusion

Use readily available evidence to ask:

1. If this item did not exist, would the available context support creating it
   now?
2. What current objective, obligation, risk, or demonstrated need warrants
   continued attention?
3. Are its material claims and assumptions still current?
4. Is there a credible owner, trigger, or horizon for reconsidering or doing
   it?
5. What would be the cost of closing it incorrectly?

Do not retain work merely because effort has already been invested or it might
be useful someday. Do not spend time improving an item before it passes this
test.

## Choose the smallest honest disposition

- **Retain** only when there is a current case for continued attention.
- **Combine** duplicates or substantially subsumed work, preserving the useful
  relationship and successor.
- **Close** work that is done, obsolete, superseded, no longer warranted, or
  requires a fresh proposal before it should compete for attention again.
- **Defer** only with a meaningful trigger, date, or owner; otherwise close and
  allow the need to return with current context.
- **Protect or escalate** active commitments, externally promised work,
  security or compliance obligations, and decisions outside the actor's
  authority.
- **Delete** only mistaken, valueless, or explicitly disposable records.
  Prefer a recoverable close or archive when history could remain useful.

When changing many records, preview the target set, dispositions, and reason
codes before applying unless the user has already approved that exact scope.
Leave a concise reason and successor link where relevant. Make reopening or
fresh nomination possible when the cost of a false closure is meaningful.

## Report

State the boundary and evidence used, summarize counts by disposition, and
expand only exceptions or uncertain cases. Distinguish recommendations from
actions actually applied. Name protected work, consequential unknowns, and any
item whose disposition needs a decision owner.
