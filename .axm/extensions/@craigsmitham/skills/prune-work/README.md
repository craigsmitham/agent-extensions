# Prune Work

Clear accumulated work by deciding what still warrants attention and closing,
consolidating, or removing what does not. The skill is tracker-agnostic and
preserves useful history instead of treating closure and deletion as the same
operation.

## Use it when

- Shrinking an unmanageable backlog.
- Closing stale, obsolete, completed, or superseded work.
- Consolidating duplicates and open loops.
- Challenging whether proposed work still deserves attention.

It does not prioritize otherwise viable work or authorize cancellation of
active commitments. Age is a review signal, not an automatic reason to close.

## Install

```sh
axm install @craigsmitham/skills/prune-work
```

Or install it through the work-management pack:

```sh
axm packs install @craigsmitham/packs/work-management
```

## Example

Ask your agent:

> Prune this backlog. Close work that is done, obsolete, superseded, or no
> longer warranted; preserve anything active or externally committed.

The skill reports the pruning boundary, disposition counts, applied or
recommended actions, protected work, and consequential uncertainty.
