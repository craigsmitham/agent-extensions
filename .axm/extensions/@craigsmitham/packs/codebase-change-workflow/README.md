# Codebase Change Workflow

Turn a bug report, feature idea, or change request into an evidence-grounded
codebase design. The pack supports three distinct stages: framing neutral
research questions, investigating the current system, and interactively
workshopping consequential design decisions with a developer.

Use it before planning or implementing a non-trivial codebase change when
current behavior or design choices need to be made explicit. It does not
generate implementation plans or modify code.

Install the complete workflow with:

```sh
axm install @craigsmitham/packs/codebase-change-workflow
```

For example, begin with a bug report to produce a research brief, use that brief
to build a cited current-state report, then use the report and original change
intent to workshop and accept a Codebase Design Record.
